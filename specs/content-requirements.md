# Content Requirements Documentation

## Content Structure

All content for this project should be stored in markdown files inside the `src/content` folder.

## Placeholder Content

Add placeholder content only for demostration purposes. Add images from unsplash when necessary.

## Personal Information and About Section

The personal information and about section should be in a separate markdown file with the following structure:

**Frontmatter data:**

- complete_name: [Full name]
- role: [Professional role]
- email: [Email address]
- location: [Location]
- social_links:
  - linkedin: [LinkedIn URL]
  - github: [GitHub URL]
  - dribbble: [Dribbble URL]

**Body content:**

- About text itself (the personal narrative and professional background)

## Projects

Each project should be in its own markdown file with the following structure:

**Frontmatter data:**

- title: [Project title]
- subtitle: [Project subtitle]
- thumbnail: [Thumbnail image path]
- liveUrl: [Live URL of the project]
- techstack: [List of technologies used]
- period:
  - start: [Start date]
  - end: [End date]
- roles: [List of roles in the project]
- overview: [Project overview text]
- outcomes:
  - title: [Outcome title]
  - description: [Outcome description]

**Body content:**

- Complete project description following a CAR Statement structure (Challenge, Actions, Results)
